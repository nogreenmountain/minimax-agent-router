# Third-Party Notices

## Headroom

MiniMax Agent Router can install and run [Headroom](https://github.com/headroomlabs-ai/headroom) as an external Python dependency for local context compression and persistent memory.

- Package: `headroom-ai[proxy]==0.33.0`
- License: Apache License 2.0
- Copyright and license terms remain with the Headroom project and its contributors.

This plugin does not vendor Headroom source code. The `headroom setup` command installs the published package into a router-managed virtual environment on the user's machine.
